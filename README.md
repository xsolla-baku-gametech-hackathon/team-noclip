# Xsolla Game Recap

**"Previously On..." for your games.** A desktop overlay that quietly watches what you're playing, remembers what happened, and gives you an AI-generated recap — screenshots, clips, and a "what you were up to" summary — the moment you come back to a game after time away.

Built at the Xsolla Baku GameTech Hackathon.

## What it does

- **Desktop app** (`software/`) hooks into whatever game you're playing, captures screenshots (F11) and video clips (F9) on demand, and logs session events in the background — no manual note-taking.
- **Website** (`website/`) is where you sign in (Google or email/password), see your game library, read AI-generated recaps of past sessions, browse captured media, and share a recap + clips via a public link.
- The two are linked by a device-pairing flow: log in once in the desktop app's tray menu, it opens the website to authenticate, and hands back a real server-issued token — no passwords or API keys ever live in the desktop build.
- Recaps are generated by an LLM (via OpenRouter) from your actual session event log — never fabricated client-side.

## Try it

1. Download the desktop app: [`software/XsollaGameRecap.exe`](software/XsollaGameRecap.exe) (Windows only).
2. Run it, launch a game, and use `Ctrl+Shift+X` to open the in-game overlay.
3. Visit the [website](https://team-noclip.vercel.app) to log in and see your recaps.

## Architecture

```
website/   React + Vite + TypeScript + Tailwind SPA, deployed to Vercel
  ├─ src/main/    Public landing page + login
  ├─ src/app/     Authenticated dashboard (Overview, My Games, Recaps, Media, Sharing, Settings)
  └─ api/         Serverless functions — auth, session sync, recap generation, media, sharing

software/  Python desktop app (Tkinter + pystray), packaged as a standalone .exe
  ├─ main.py          Entry point, game detection, hotkeys
  ├─ gamebar.py        In-game overlay UI
  ├─ recap_manager.py  Local session/event logging
  ├─ sync_client.py    Syncs sessions/media to the website
  └─ ai_recap.py       Calls the website's recap API

games/     Per-game hook/integration configs
```

## Running locally

**Website:**
```bash
cd website
npm install
npm run dev -- --port 5183
```
Needs a Postgres database (`DATABASE_URL`), a `SESSION_SECRET`, and `OPENROUTER_API_KEY` for recap generation — see `website/.env.example`.

**Desktop app:**
```bash
cd software
pip install -r requirements.txt
python main.py
```
Point it at your deployed website via `software/.env` — see `software/.env.example`.
